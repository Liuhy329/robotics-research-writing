# 验证流程与记录格式

本文件提供检查方法，没有历史验证日志。任务产生的记录保存到用户研究工作目录的 `.robotics-writing/validation.md`。

## 格式检查

修改 skill 本身时检查 YAML、名称、相对路径和链接；可用时运行 skill 验证器。更新个人知识时检查规则及来源编号、文件位置与证据锚点。文件存在不等于已被加载，也不等于写作效果通过验证。

## 写作行为检验

- 用固定事实与同一任务比较，优先采用真实且未参与规则提炼的材料；前后仅改变待检验规则或 skill 的使用状态。
- 检查事实忠实、主张—证据匹配、结构、清晰度、术语、语言和任务适配；不要以篇幅、词汇难度或“像顶刊”打分。
- 没有真实作者材料时可使用明确标为构造案例的边界检查，不称为真实写作迁移验证。针对案例调过规则后，该案例不能再称独立验证。
- 发现错误时修具体条件或动作；事实错误和无依据加强必须修复。无法解释的冲突保留并降低规则优先级。
- 核验隐私边界：个人生成物没有写入公开 skill；任何外部分享均在用户授权范围内。

## 记录字段

| 字段 | 内容 |
|---|---|
| 日期与任务 | 本次请求、版本或待检验规则 |
| 输入与范围 | 真实材料/构造案例、固定事实、可访问的章节/图表 |
| 操作 | 实际执行的检查或比较，以及依赖的工具 |
| 结果与证据 | 通过/失败/未检验，证据位置及观察到的问题 |
| 修正 | 受影响条目、调整理由及复查结果 |
| 未完成项 | 仍缺少什么输入，影响哪项结论 |

只记录实际完成事项，不把格式通过写成真实性验证，不把脚本离线测试写成机构下载成功。
