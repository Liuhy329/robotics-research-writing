# 条件化写作规则模板

本文件没有预先学习的规则。个人规则保存到用户研究工作目录的 `.robotics-writing/writing-rules.md`。对已经存在的规则库沿用其稳定编号，不因更换资料路径重编号。

|---|---|---|---|---|

## 单条规则字段

| 字段 | 内容要求 |
|---|---|
| 稳定编号与名称 | 唯一编号及明确改变哪项写作决策的名称 |
| 状态 | 候选、适用、范围修订、冲突待查、暂停；按实际证据填写 |
| 动作 | 在什么条件下采用什么写法 |
| 适用条件 | 研究类型、读者、章节职责和所需证据 |
| 不适用条件 | 反例或不能直接迁移的情境 |
| 可观察事实 | 来源编号及页码/章节/段落/图表锚点，附短引文或忠实转述 |
| 解释与依据 | 写法承担的论证作用；区分原文事实与分析解释 |
| 证据范围 | 实际阅读范围、独立研究关系、支持与反例；不以出现次数替代质量 |
| 应用示范 | 已授权作者事实，或明确标注的结构占位符/虚构示例 |
| 检验 | 对应验证记录及实际结果；未检验时明示 |
| 变更记录 | 日期、原状态、变更、来源、理由 |

一篇论文中的常规写法可作为候选观察，不能自动升级为领域标准。没有增量时登记已读或增加例证，避免堆叠同义条目。正文不用个人规则编号。
