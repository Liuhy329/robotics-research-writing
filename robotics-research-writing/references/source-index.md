# 来源与阅读范围模板

本文件没有任何文献登记或语料索引。新记录保存到用户研究工作目录的 `.robotics-writing/source-index.md`；原文、转换文件与蒸馏文件均留在个人资料库。

## 单篇记录字段

- 身份：稳定编号、正式题名、作者、年份、期刊、DOI或出版者稳定链接；保留未核实字段。
- 版本：正式版/预印本/修订稿等；主文、正文加补充材料、独立附件等角色；关联同一研究的其他版本。
- 文件：原件及 Markdown 路径、页数、字节数、SHA-256；文件名不替代身份核验。
- 来源：检索条件、实际查看范围、入选理由、获取时间及正常访问路线；不存签名下载地址、cookies、账户令牌或凭据。
- 阅读：实际章节/页码/图表范围、未恢复的转换问题、全文/摘要/节选限制。
- 蒸馏：记录路径、所支持或修订的规则、反例/冲突、无增量时的登记理由。
- 作者反馈：仅记录用户授权保存的反馈及其对应任务，不把反馈误写为论文结论。

采用稳定编号，在去重与版本关联后分配。按“已获取待核验 → 已核验待阅读/蒸馏 → 已阅读/蒸馏”报告实际状态；PDF、正文、附件与独立研究分别计数。

## 文件命名与分类

按核实后的正式标题命名，操作系统不允许的字符用兼容字符替换；正式题名字段不变。必要时添加版本或附件后缀，重名先比较哈希和版本，不覆盖原件。使用用户已有分类；尚无分类时按标题存放，细分信息可用标签表达。
